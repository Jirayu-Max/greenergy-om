รายละเอียดงาน

👤 Operator & อีเมล — ส่งงานเข้า Calendar ของแต่ละคน

คลิกงานในปฏิทิน → กดส่งเข้า Calendar ของ Operator (Google / Outlook / ไฟล์ .ics) หรือกด “ส่งงานเดือนนี้” ที่แถวของแต่ละคนเพื่อได้ไฟล์ .ics รวมทุกงานของเดือน
🔗 ส่งงานเข้า Outlook / Teams ทันที (Power Automate)
วิธีตั้งค่า (ทำครั้งเดียว ~5 นาที)
  1. เปิด make.powerautomate.com (Trigger “HTTP request” เป็น Premium connector — ต้องมีสิทธิ์ Power Automate Premium) → Create → Instant cloud flow → Trigger: When an HTTP request is received (Who can trigger = Anyone)
  2. เพิ่ม action Compose ใส่ Expression: json(base64ToString(triggerBody()?['$content']))
  3. เพิ่ม Office 365 Outlook → Create event (V4) แล้วกรอกแต่ละช่องโดยกด Expression (fx): Calendar id=Calendar • Subject=outputs('Compose')?['title'] • Start time=concat(outputs('Compose')?['start'],'T08:00:00') • End time=concat(outputs('Compose')?['end'],'T17:00:00') • Time zone=(UTC+07:00) Bangkok, Hanoi, Jakarta • Required attendees=outputs('Compose')?['attendeesText'] • Body=outputs('Compose')?['description'] • Location=outputs('Compose')?['location']
  4. Save → คัดลอก HTTP POST URL มาวางในช่อง Flow URL ด้านบน แล้วกด “ทดสอบส่ง”
  5. งานจะถูกสร้างใน Outlook Calendar ของเจ้าของ Flow และส่งคำเชิญให้ Operator ทุกคน → เห็นใน Outlook และ Teams Calendar ของแต่ละคน
⚠️ ใครมี URL นี้ก็สั่งสร้างนัดหมายได้ อย่าแชร์ และ URL จะอยู่ในไฟล์ Backup ด้วย
