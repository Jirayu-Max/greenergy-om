1. เริ่มต้นใช้งาน

ทุกคนต้องมีบัญชีที่ผู้ดูแลระบบสร้างให้ ระบบไม่เปิดให้สมัครเอง

  1. เปิด หน้าระบบ ด้วย Chrome หรือ Edge
  2. ใส่อีเมลและรหัสผ่านชั่วคราวที่ได้จากผู้ดูแลระบบ แล้วกด เข้าสู่ระบบ
  3. ครั้งแรกระบบจะให้ตั้งรหัสผ่านใหม่ของตัวเอง (อย่างน้อย 8 ตัวอักษร)

2. Corrective maintenance

ใช้แบบ "รับเรื่องไว้ก่อน ค่อยวางแผนทีหลัง": บันทึกทันทีที่ได้รับเรื่อง แล้วค่อยใส่วันเริ่มงานเมื่อรู้ว่าทีมว่างวันไหน

เพิ่มงานใหม่

  1. กด ➕ เพิ่มรายการงาน
  2. เลือก Owner แล้วเลือก Project (แสดงเฉพาะโครงการของ Owner นั้น)
  3. กรอกวันที่ ประเภทงาน Operator และรายละเอียด แล้วกด 💾 บันทึก
ช่องความหมายบังคับ
Received Dateวันที่ได้รับเรื่อง (ใส่วันนี้ให้อัตโนมัติ)✅
Start Planวันเริ่มงานในแผน ใส่ทีหลังได้–
Finishวันจบงานในแผน–
SLA (ชม.)เป้าหมายเวลาทำงาน–

งานจะขึ้นในปฏิทินก็ต่อเมื่อมี Start Plan

Work Order

รูปแบบ WO-ปปดด-ลำดับ-รหัสงาน-รหัสโครงการ เช่น WO-2604-042-CMWTY-TAP-C

  • เว้นว่างได้ ระบบออกเลขให้เอง นับใหม่ทุกเดือน (ตามเดือนของ Start Plan หรือ Received Date)
  • รหัสงานมาจาก Type of work เช่น Corrective Maintenance (Warranty) = CMWTY • รหัสโครงการมาจากชื่อโครงการ
  • แก้รหัสได้ที่ปุ่ม 🔤 รหัส WO • เปลี่ยน Type of work หรือ Project ภายหลัง ส่วนท้ายเลขจะเปลี่ยนตาม แต่เลขลำดับคงเดิม
  • 🔢 สร้างเลข WO ให้งานเดิม ออกเลขให้งานที่ยังไม่มี และต่อท้ายรหัสให้เลขเดิม

Operator และรายละเอียด

  • Operator เลือกจากรายชื่อพนักงาน แสดงเป็น "ชื่อจริง (ชื่อเล่น)" • ＋ เพิ่มช่อง Operator เพิ่มคน • ＋ ข้างช่อง เพิ่มพนักงานใหม่ • 🗑 เอาคนนั้นออกจากงานนี้
  • Detail เพิ่มได้หลายข้อ แต่ละข้อบันทึกวันที่ เวลา และชื่อผู้อัปเดตให้อัตโนมัติ

ในตาราง

  • คลิกตรงไหนก็ได้บนแถวเพื่อเปิดแก้ไข
  • Days Passed นับจาก Received Date ถึง Finish (ยังไม่มี Finish นับถึงวันนี้)
  • ค้นหาและกรองตามช่วงวันที่ ประเภท สถานะ Owner ได้จากแถบด้านบน • Export CSV ได้

3. Plan PM & AN

แผนงาน QPM (Quarterly PM) และ AN (Annual) ของทุกโครงการ พร้อมสรุปและกราฟ BOQ เทียบ Actual

  1. กด ➕ เพิ่มงาน → เลือก Owner และ Project (ข้อมูลโครงการเติมให้เองจาก Project list OM)
  2. กรอก Activity, ประเภท (QPM/AN), Round, Start และจำนวนวัน (END คำนวณให้)
  3. กรอก BOQ, Actual, Progress (%), Subcontractor และ Operator แล้วบันทึก • เพิ่มหลายแถวในฟอร์มเดียวได้
Progressสถานะ
0%ยังไม่เริ่ม
1–99%กำลังดำเนินการ
100%เสร็จแล้ว (แถวสีเขียวในตารางแผนงาน)

ตั้งสถานะ "เลื่อน" เองได้ในฟอร์ม • คลิกแถวเพื่อแก้ไข • งานที่มี Start ขึ้นในปฏิทินอัตโนมัติ

4. Smart O&M Calendar

รวมงานจาก Corrective maintenance และ Plan PM & AN • สลับมุมมองด้วยปุ่ม 📅 ปฏิทิน / 📋 ตารางแผนงาน • กรองตาม Operator หรือ Subcontractor

มุมมองปฏิทิน

  • คลิกงานเพื่อดูรายละเอียด แก้ไข หรือลบ
  • ลากงานไปวันอื่นเพื่อเลื่อนทั้งช่วงงาน (จำนวนวันเท่าเดิม)
  • Resource Planning ด้านล่างบอกจำนวนงานต่อวันของแต่ละทีม/คน (ส้ม/แดง = งานซ้อน)

ตารางแผนปฏิบัติงานประจำเดือน

  • แสดงครบทุกวัน • สีแถว: เขียว = เสร็จ, ครีม = เสาร์–อาทิตย์, แดงอ่อน = วันหยุด
  • ช่องผู้ปฏิบัติ 4 ช่องเป็น Drop-down (เปลี่ยนเฉพาะวันนั้น) • ติ๊ก "เปิด Work เรียบร้อย" และใส่ผู้รับผิดชอบได้
  • 📗 Export Excel ได้ไฟล์ A4 แนวนอนพร้อมพิมพ์ • 🖨️ พิมพ์ จาก browser

วันหยุด

คลิกช่องวันที่ในตารางแล้วพิมพ์ชื่อวันหยุด (ลบข้อความ = ยกเลิก) หรือกด 🎌 กำหนดวันหยุด

ปรับงานเฉพาะวัน

ต้องการทำอย่างไร
หยุดงานวันเดียวชี้แถวในตารางแผนงาน → ⛔ หยุดวันนี้ • หรือคลิกงาน → ⛔ หยุดงานวันนี้
คืนงานวันที่หยุดคลิกงานในวันอื่น → "วันที่หยุดงาน" → ↺
เปลี่ยนคนเฉพาะวันเปลี่ยน Drop-down ในแถววันนั้น • หรือคลิกงาน → ติ๊กคนใน "📅 ปรับเฉพาะวันที่…" → 💾
กลับไปใช้คนตามทั้งงานกด ↺ ใช้ตามงาน ที่ป้าย 📅 ผู้ปฏิบัติเฉพาะวันนี้
เปลี่ยนคนทั้งงาน✏️ แก้ไข แล้วแก้ในฟอร์มงาน

5. Dashboard และ Project list OM

📊 Dashboard

  • เลือกช่วงเวลา (7/30/90 วัน, เดือนนี้, ปีนี้, ทั้งหมด, กำหนดเอง) — ค่าเริ่มต้นคือ "ปีนี้"
  • Corrective maintenance: เข้ามา = Received Date อยู่ในช่วง • แก้ไขแล้ว = สถานะเสร็จแล้ว • ค้าง = ยังไม่เสร็จ ณ สิ้นช่วง • เลือก "ทั้งหมด" ตัวเลขจะตรงกับหน้า Corrective maintenance
  • คลิกตัวเลขเพื่อดูรายการ • 🖨️ พิมพ์ / PDF สำหรับนำเสนอ

📑 Project list OM

  • เก็บ Capacity, ประเภท, ภูมิภาค, จังหวัด, Owner, สถานะ, วันเริ่ม/สิ้นสุด OM และ Warranty
  • รายชื่อโครงการและ Owner ที่นี่คือตัวเลือกในฟอร์มงาน — ควรเพิ่มโครงการใหม่ที่นี่ก่อน

6. รายชื่อพนักงาน

เป็นตัวเลือก Operator ของทุกหน้า แสดงเป็น "ชื่อจริง (ชื่อเล่น)" ไม่แสดงนามสกุล (ยังไม่มีชื่อไทย ใช้ชื่ออังกฤษแทน)

  1. กด ➕ เพิ่มพนักงานใหม่ → 📷 เลือกรูป (ระบบย่อรูปให้)
  2. กรอกชื่อจริง นามสกุล ชื่ออังกฤษ ชื่อเล่น ตำแหน่ง ทีม เบอร์โทร อีเมล วันเริ่มงาน (อายุงานคำนวณให้)
  3. กด 💾 บันทึก — ถ้างานเดิมใช้ชื่อเล่นหรือชื่อเก่าของคนนี้ ระบบจะถามว่าจะเปลี่ยนให้ตรงกันหรือไม่
  • คลิกการ์ดเพื่อแก้ไขหรือลบ (ลบพนักงานไม่ลบชื่อออกจากงานเดิม)
  • 📥 นำเข้าจากไฟล์ รับไฟล์ JSON จาก Greenergy Org Chart นำเข้าซ้ำได้ไม่สร้างซ้ำ
  • ใส่อีเมลให้ตรงกับบัญชีเข้าระบบ จะได้ใช้ชื่อนี้เป็นชื่อผู้อัปเดต

7. สวัสดิการพนักงาน ใหม่

งบคนละ 500 บาท/เดือน ยอดที่เหลือสะสมได้ภายในปี (เริ่มใหม่ทุกมกราคม) เริ่มให้ตั้งแต่ พฤศจิกายน 2026

เดือนสิทธิ์ตัวอย่าง: พ.ย. ใช้ 300
พ.ย. 2026500เหลือ 200
ธ.ค. 2026500 + ที่เหลือสิทธิ์ 700
ม.ค. 2027เริ่มใหม่ 500ยอดปีก่อนไม่ยกไป

ดูยอด

  • การ์ดรายคนแสดงยอดใช้ / สิทธิ์ / คงเหลือ (เขียว ปกติ • เหลือง เกิน 80% • แดง เกินสิทธิ์) และยอดทั้งปี
  • เลือกหลายคน: คลิกการ์ดหรือติ๊กมุมขวาบน แถบด้านบนสรุปสิทธิ์รวม ใช้ไป และคงเหลือรวมของคนที่เลือก
  • เลื่อนเดือนด้วย ◀ ▶ • 📗 Export Excel ได้ชีตสรุปรายคนและรายการใช้

บันทึกการใช้

  1. กด ➕ บันทึกการใช้ (หรือ ＋ ใช้ บนการ์ด / ➕ บันทึกการใช้ให้ N คนนี้)
  2. ติ๊กพนักงานได้หลายคน (ค้นหาได้ ตัวเลขขวา = คงเหลือ)
  3. ใส่จำนวนเงิน เลือก ต่อคน หรือ ยอดรวม หารเท่ากัน แล้วใส่ "นำไปใช้อะไร" ประเภท และเลขใบเสร็จ
  4. กดบันทึก — ระบบแยกเป็นรายการละ 1 คน และเตือนถ้าเกินสิทธิ์

⚙️ ตั้งค่า: งบต่อคน • เดือนที่เริ่มให้สวัสดิการ • สะสมหรือไม่ • ติ๊กคนที่ไม่ได้รับสวัสดิการออก (คนที่ยังไม่ถึงวันเริ่มงานยังไม่ได้สิทธิ์)

8. สำหรับผู้ดูแลระบบ

ปุ่มคลาวด์มุมขวาบน → 👥 จัดการผู้ใช้

  1. กรอกอีเมลและชื่อที่แสดง (ใช้เป็นชื่อผู้อัปเดตในรายละเอียดงาน)
  2. รหัสผ่านครั้งแรกสุ่มให้ (🎲 สุ่มใหม่) • เลือกสิทธิ์และแท็บที่เข้าถึงได้
  3. กด ➕ สร้างผู้ใช้ → 📋 คัดลอก ส่งให้ผู้ใช้ (รหัสแสดงครั้งเดียว)
  • เปลี่ยนสิทธิ์/แท็บแล้วกด 💾 บันทึกสิทธิ์ • 🔑 รีเซ็ตรหัส • 🗑 ลบผู้ใช้ (ข้อมูลงานไม่ถูกลบ)
  • การซ่อนแท็บมีผลบนหน้าจอ ส่วนสิทธิ์ดูอย่างเดียว/แก้ไขได้บังคับจริงที่ฐานข้อมูล

ไม่เห็นปุ่มหรือหน้าตาใหม่หลังอัปเดตกด Ctrl+F5
กดแก้ไขแล้วขึ้น "สิทธิ์ดูอย่างเดียว"ขอสิทธิ์ "แก้ไขได้" จากผู้ดูแลระบบ
ปุ่มคลาวด์ขึ้น ⚠️ ยังไม่ได้บันทึกตรวจอินเทอร์เน็ต ระบบจะลองบันทึกซ้ำเอง อย่าปิดหน้าเว็บจนขึ้น ☁️ ซิงก์แล้ว
บันทึกงานเก่าไม่ได้ใส่ Received Date ก่อน (ช่องบังคับ)
งานไม่ขึ้นในปฏิทินใส่ Start Plan หรือตรวจตัวกรอง Operator / Subcontractor
งานหายไปบางวันในตารางแผนงานอาจถูกหยุดเฉพาะวัน — คลิกงานในวันอื่นแล้วกด ↺ ที่ "วันที่หยุดงาน"
ไม่เห็นชื่อใน Drop-down Operatorเพิ่มคนนั้นในแท็บ 👥 รายชื่อพนักงาน หรือกด ＋ ข้างช่อง
ตัวเลข Dashboard ไม่ตรงหน้างานDashboard เริ่มที่ "ปีนี้" — เลือก "ทั้งหมด" เพื่อเทียบกับทุกงาน
ลืมรหัสผ่านให้ผู้ดูแลระบบกด 🔑 รีเซ็ตรหัส
เปิดเว็บไม่ได้หลังไม่มีคนใช้นานผู้ดูแลเข้า Supabase แล้วกด Restore project
